# Welcome to Eludesion !! 

### Overview
Eludesion is a 2d multilevel run and gun game, where the main idea is to defeat incoming threat from invaders. However, the game also challenges the gaurdian(the player) with mission goals, boss levels, and conflicting gaurdian decisions. Throughout the game the player will be able to play the game as they are doing other things, wether its work, watch youtube, or search things up, this gives the player more accesablility and freedom with the game.
